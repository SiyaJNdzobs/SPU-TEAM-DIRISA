# 1. Defined Problem Statement

This folder contains the official Problem & Solution Statement deliverables for the SPU-DIRISA Team entry in the DIRISA Student Datathon Challenge:

- **Document:** [`Problem_and_Solution_Statement.pdf`](Problem_and_Solution_Statement.pdf)
- **Problem Focus:** Diagnosing structural voter turnout collapse across all 921 wards in KwaZulu-Natal ahead of the 2026 Local Government Elections.
- **Solution:** Multi-source empirical feature fusion and Random Forest predictive modeling forecasting ward-level participation and non-voting population gaps.
